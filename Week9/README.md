# **Week 9 — Neural Networks Basics (ANN Implementation)**
This week focuses on understanding the **basics of Artificial Neural Networks (ANNs)** using Keras and applying them to the Fake News Detection dataset.

## Steps Taken
* Imported required libraries

* Loaded Fake & True datasets

* Added labels and merged both files

* Created combined text column

* Applied TF-IDF vectorization

* Split data into train/test

* Built and compiled ANN model

* Trained ANN (5 epochs)

* Evaluated accuracy & report

* Compared ANN with earlier models

##  **Key Insights:**

* The dataset showed clear differences in writing style between fake and real news.

* After preprocessing, the ANN improved but still performed slightly below Logistic Regression.

* Most errors occurred on short or opinion-based articles with limited context.

* The ANN can be improved with more tuning or advanced models like Word2Vec, LSTM, or BERT.
